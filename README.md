A program that writes one concrete, costed, day-by-day plan an AI agent can execute itself to turn $100 into the most money in 30 days — for the [make.fun bounty "The plan make.fun will carry out in public"](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138).

## How it works

`main.ts` (Node 22, stdlib only, no network) writes the plan to `/output/entry.txt`: day 1 lists AI cold-email setup gigs at $150 on Upwork/Contra pitched to Shopify stores already running Meta ads, days 2–10 deliver two setups a day to collect reviews, days 11–30 raise the rate to $250, upsell $400/mo retainers, and reinvest 30% in Apollo credits — with a stop below $40.

```sh
node main.ts   # writes /output/entry.txt (269 chars, within the 1–280 gate)
```
